Website accessibility

Accessibility Statement

Many of the people who use this site are living with cognitive, visual, or balance-related changes after a brain injury, stroke, or concussion. We hold this site to the WCAG 2.2 Level AA standard, and we want it to work well for you regardless of how you browse.

What we have built in

  • A skip link at the very start of every page, so keyboard users can jump straight past the navigation to the main content.
  • A navigation menu, including the mobile menu and its dropdowns, that is fully operable by keyboard alone.
  • Reduced-motion support: the leaf video on the homepage, and every other animation on the site, is switched off automatically if your device is set to reduce motion. You still see a still image in its place.
  • Frequently asked questions built with the browser's native expand and collapse control, so they work the same way with a keyboard, a screen reader, or a mouse.
  • Visible focus outlines on every link, button, and form field, so you can always see where you are on the page.
  • Body text set no smaller than 17px, with generous line spacing, for easier reading.

We review this statement and the site itself periodically, since accessibility is not a one-time fix. If you have feedback on how we could do better, we would like to hear it.
